# Texas filing edits and corrections

Read hutchrok-texas-sos-portal for secure access and authorization and hutchrok-texas-vvl-waiver for fee relief. Identify exact entity/file number, original instrument/date, actual disposition, proposed change and evidence. Preserve signed and accepted originals in private storage; create versioned working copies and a field-level before/after table.

| Observed condition | Appropriate workflow |
|---|---|
| Unsubmitted draft | My Drafts; edit verified fields, save and preview. |
| Received with Edit Submission offered | Inspect tracking record and current agency rules before editing. Bind approval to revised version. Stop Submission is a separate cancellation needing specific authority. |
| Rejected | Read every reason; tracking record → Edit Rejected Submission → correct → preview → Add To Cart. The current guide allows resubmission within 30 days; verify actual deadline and fee treatment. |
| Accepted instrument with original error | Research Certificate of Correction (Form 403) and applicability; prepare a separate packet. Never rewrite the accepted record as if the state changed it. |
| New decision or changed facts after acceptance | Research amendment (Form 424 when applicable), registered agent/office change (Form 401 when applicable) or transaction-specific route. Do not portray a later change as an original error. |

Check [current forms](https://www.sos.state.tx.us/corp/forms_boc.shtml), [Form 403](https://www.sos.state.tx.us/corp/forms/403_boc.pdf) and [portal guide](https://www.sos.state.tx.us/corp/bf-guide.shtml). Form 403 checked 2026-10-05 was revised 09/26 and displayed $15 base fee; recheck and independently verify waiver treatment. Rejected resubmission is not automatically Form 403. Route uncertain correction-vs-amendment questions for qualified review while continuing factual preparation.

Reconcile present entity name/file number, instrument/date, identified errors, exact replacement text, signatory authority, agent consent where relevant, effectiveness and attachments against current instructions. Deliver unsigned review packet, change table, rejection-response matrix when applicable, fee/waiver review, secure evidence references and action approval request. Never create a signature or certify facts on the owner's behalf.

Use existing OS transitions: CORRECTION_REQUIRED/RESUBMITTED only when the observed disposition and current formation case support them. An accepted entity's later correction/amendment needs a separate related case/action; never reopen terminal formation states or pretend placeholder MCP tools submit filings. Capture actual receipt separately from agency disposition. Check history before retrying uncertain submissions.
