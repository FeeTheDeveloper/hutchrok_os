# Filings

Repository home for Hutchrok filing materials that are safe to version.

| Path | Contents |
|---|---|
| `forms/` | Blank official form templates (no client data) |

## Rules

- **Blank templates only.** Completed, signed, or client-specific filings are
  RESTRICTED/CONFIDENTIAL and never enter Git. They stay in the client's
  Dropbox/Drive record and are referenced by ID from the OS.
- Before using a template for a filing, confirm it is still the agency's
  current revision (see `hutchrok-filing-documents` skill and
  `filing-protocol.md`). Replace the file here when the agency revises it and
  update the index.
